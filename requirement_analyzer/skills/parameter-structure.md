# Parameter Structure Template

> 用途：analyzer 结构化需求时的标准输出格式
> 使用场景：完成需求分析后，按本模板输出结构化参数

## 使用方法

1. 读取 clarifier 的澄清结果
2. 区分"必须明确"和"建议明确"两类参数
3. 为每个参数指定类型、约束、默认值
4. 输出结构化 JSON + 可读 Markdown

## 参数类型定义

| 类型 | 说明 | 示例 |
|------|------|------|
| string | 字符串 | 名称、描述 |
| int | 整数 | 数量、人数 |
| float | 小数 | 价格、百分比 |
| boolean | 是/否 | 开关选项 |
| enum | 枚举 | 状态、等级 |
| list | 列表 | 清单、选项 |
| dict | 复合 | 嵌套结构 |

## 输出格式模板

```markdown
## 参数体系

### 必须明确（缺一不可）
| 参数名 | 类型 | 约束 | 默认值 | 说明 |
|--------|------|------|--------|------|
| ... | ... | ... | ... | ... |

### 建议明确（可推理）
| 参数名 | 类型 | 约束 | 默认值 | 说明 |
|--------|------|------|--------|------|
| ... | ... | ... | ... | ... |

## 约束条件

1. **硬约束**（必须满足）
   - ...

2. **软约束**（尽量满足）
   - ...

## 验收标准

| 标准ID | 描述 | 验证方式 |
|--------|------|---------|
| AC1 | ... | ... |
| AC2 | ... | ... |

## 复杂度评估

| 维度 | 评估 | 理由 |
|------|------|------|
| 参数数量 | N个 | - |
| 约束复杂度 | 低/中/高 | - |
| 外部依赖 | 有/无 | - |

### 复杂度判定

- **低**：参数 < 10，约束简单，无外部依赖
- **中**：参数 10-30，有少量约束
- **高**：参数 > 30，约束复杂，有外部依赖
```

## JSON Schema 输出

每个 analyzer 产出必须包含：

```json
{
  "parameters": {
    "param_name": {
      "type": "string|int|float|boolean|enum|list|dict",
      "required": true,
      "constraints": "约束描述",
      "default": null,
      "description": "参数说明"
    }
  },
  "constraints": {
    "hard": ["硬约束列表"],
    "soft": ["软约束列表"]
  },
  "acceptance_criteria": [
    {"id": "AC1", "description": "...", "verification": "..."}
  ],
  "complexity": "low|medium|high"
}
```
